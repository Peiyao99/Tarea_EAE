## 2. 产品气质
- **做什么、给谁**：把想法、草图、三视图或 3D 模型变成能直接裁剪缝制的毛绒纸样。主力是入门的兴趣用户，另有申请开通的创作者和买材料包的人。用起来的感觉：温暖、手作、有把握，像在裁剪台上被人手把手带着做。
- **设计语言**（见 `evidence/style-audit.md`）：暖纸底 #F8F5F0，铁锈红 #B83C0A 强调，3D 舞台炭灰 #2B2A33，缝线 #F3A27A；Noto Sans SC 正文 + Noto Serif SC 标题；18–20px 圆角卡片，柔和暖阴影。没有暗色主题。
- **母题候选**：纸样裁片（净样线 + 缝份虚线 + 刻口）、缝线虚线、切割垫网格、3D 部位与裁片同时高亮、从一只恐龙到一份材料包的用户历程。

## 4. 选择与理由（推荐 C，待用户确认）
- **为什么是 C**：用户定的范围是完整历程，兴趣用户到创作者再到买家，本身就是一条路。9:16 竖屏向下行进和小红书刷屏的手势一致。暖纸底和缝线来自产品自己的设计语言，和毛绒的温度相符。用同一只恐龙串起全片，让观众记住一个具体结果，而不是一串功能名。B 的 3D ↔ 纸样匹配剪辑作为 C 里的一场重头戏保留。
- **本片专属手法**：
  1. 因为产品的核心单位是带缝份虚线的裁片 → 全片用一条铁锈红缝线当路径和转场，镜头沿线下移，线在转场时"缝"到下一站。
  2. 因为 3D 部位和裁片会同时高亮 → 匹配剪辑：3D 里腿亮起，缝线从腿拉下，落到纸样 L1 上。
  3. 因为用户缝好登记后可以投稿案例库，案例又出现在首页的照着案例做一只 → 首尾闭环：开场是别人正在预订的材料包，结尾回到同一只恐龙，开裁进度 32 → 33。
  4. 因为站点就是用户历程的阶段 → 编号站牌 01 想法、02 自己缝出来、03 成为创作者、04 被别人买到，替代上一批片子的身份标签。
- **与本工作区既往影片的区别**：
  - 开场：用结果倒叙（材料包预订），不用问句大字。
  - 章节：缝线站牌，不用身份标签、关卡进度条或第几话。
  - 背景：浅色纸面，不用深色舞台、网点或速度线。
  - 转场：缝线牵引加一次匹配剪辑，不用圆形或斜切擦除。
  - 配乐：钢琴和轻鼓，不用马林巴或失真吉他。

## 5. 画面规范（方向 C）
- **画幅与底色**：1080×1920，30 fps。底 #F8F5F0，叠 34px 点阵 rgba(94,90,82,.13)；3D 只出现在产品界面和匹配剪辑的舞台里。
- **安全区**：
  - 关键文字 x ∈ [84, 996]。
  - y ≥ 150，避开小红书顶栏；y ≤ 1670，底部留 13%。
  - 下半屏右侧 120px 不放关键文字，避开点赞栏。
- **字号阶梯**：
  - 英文主标题：Instrument Serif Italic 110–132px，铁锈红。
  - 中文标题：Noto Sans SC 900，56–92px，行高 1.28，墨色。
  - 站牌：Noto Sans SC 900 52px，编号为等宽 30px 白字红底。
  - 界面内文字保持产品原字体。
- **上镜倍数**：手机界面 1.9–2.3 倍，正文 13px 放大后为 25–30px。微距镜头最高 2.6 倍。完整屏幕只用于每站的建立镜头。
- **动效语法**：
  - 镜头沿缝线移动：power2.inOut，0.8–1.2 秒。
  - 界面卡片入场：位移 60–120px，带 2–4° 旋转后落定，expo.out，0.5 秒。
  - 标题：行遮罩上移揭示，0.4 秒，逐行错开 0.08 秒。
  - 缝线：strokeDashoffset 画出。
  - 真实交互（打字、点击、开关）落在拍点上。
  - **不用**：回弹、贴纸、发光、彩虹色、身份标签、居中不动的手机。
