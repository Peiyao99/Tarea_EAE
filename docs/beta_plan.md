# 第一次内测方案：打版师验证

## 目的

不是验证功能是否完整，而是回答四个问题：

1. 模板生成的纸样离打版师认可的可缝制水平差多少，差在哪些裁片、哪些边
2. 打版师在真实工作流里会在哪一步离开产品回到自己的工具（CLO3D、AI、手工）
3. 导出的文件能否直接进入他们的下游（打印、绘图仪、CAD、工厂）
4. 参数化的表达方式（滑块 + 联动）对专业用户是否成立，还是他们只想直接拖点

每个问题都对应具体的数据来源，见下文。

## 参与者

- 5 到 8 位打版师，覆盖至少两类背景：工厂开版（熟 CAD 与 DXF）、独立设计师（熟手工与 PDF 打印）
- 每人分配匿名 user_id，姓名对照表只存在 `research/testers.csv`
- 内测周期两周；第一周自由使用，第二周执行任务脚本

## 内测版本范围

内测版 = Playbook 阶段 1 全部 Step。包含：预设与参数、2D 编辑器（含手动编辑）、纸样体检、全格式导出、事件记录、应用内反馈、事件包导出。

不包含：3D 导入与展平、充棉模拟、账号与云同步、商城。打版师问起时如实说明这些在后续版本。

## 任务脚本（第二周）

每个任务结束后弹出结构化反馈表，并要求导出事件包。

### 任务 A：用预设做一只熊并交付

- 选熊预设，按自己习惯调参数，导出 PDF 和 DXF
- PDF 打印并量校验方块；DXF 导入自己常用的 CAD
- 要回答：哪些裁片你会直接用，哪些必须改，哪些完全不能用；导入 CAD 后哪里出问题
- 数据：param_changed 序列、manual_edit 热点、export 格式选择、反馈表评分

### 任务 B：把模板改到你满意为止

- 在任务 A 的基础上，用手动编辑把不满意的裁片改到可打样
- 要回答：改了什么、为什么；哪些操作找不到或不顺手
- 数据：manual_edit 的 before/after 差量按裁片和边聚合，这是模板缺陷的直接证据

### 任务 C：参数极限测试

- 把头围、耳位角度、身长等参数拉到范围两端
- 要回答：哪个参数在什么值之后纸样就不合理了；哪些参数你根本不会碰
- 数据：check_failed 事件与参数值的关系、参数触碰频率

### 任务 D（可选）：对比自己的版

- 打版师提供同类动物的自有纸样（只存 `research/`），与模板版并排比较
- 由我做半结构化访谈，记录差异点

## 记录什么

### 事件流（自动）

字段规范见 `docs/event_spec.md`。内测关注的事件：

| 事件 | 回答的问题 |
|---|---|
| preset_selected, param_changed | 哪些参数被频繁调整，调整范围分布 |
| manual_edit（含对象 ID 与差量） | 模板在哪些裁片、哪些边上不可信 |
| check_failed / check_passed | 体检规则是否与打版师判断一致，误报率 |
| export（格式、纸张、页数、耗时） | 下游需求分布，导出性能 |
| feedback_submitted | 结构化评分与文字 |
| session_start / session_end | 每次使用时长，中途放弃点 |
| feature_missing（用户主动标记） | 想做但做不了的操作 |

### 应用内反馈（半自动）

- 每个裁片可以右键标记问题：类型（尺寸、形状、缝份、记号、其他）+ 文字，写入 feedback_submitted 并带裁片 ID
- 导出完成后弹出三题评分：能否直接使用、文件是否正确打开、与你的工作流差距（1 到 5）
- 工具栏常驻一个按钮：我想做但做不了，点击后记 feature_missing 并让用户描述

### 访谈（人工）

每位打版师内测结束后 45 分钟访谈，围绕四个目的提问。记录存 `research/interviews/`。

## 数据回收

- 打版师在设置页一键导出事件包（JSON，含全部事件与最终纸样），通过约定渠道发回
- `scripts/beta_report` 读取多份事件包，输出：
  - 每位打版师的漏斗：进入 → 调参 → 手动编辑 → 体检 → 导出
  - manual_edit 按裁片 × 边的热力表
  - 参数触碰频率与取值分布
  - check_failed 规则分布
  - 导出格式与纸张分布
  - 全部反馈文本按裁片聚合
- 报告为 Markdown，附在 `docs/beta_report_YYYYMMDD.md`

## 成功标准

内测不设通过与否，只设决策阈值：

- 任一裁片被超过一半打版师手动修改：模板参数模型要重做该裁片
- 任一导出格式在超过两位打版师的下游打不开或比例错：导出为阻断级缺陷
- 手动编辑事件占全部编辑事件比例超过 60%：参数化表达对专业用户不成立，下一版优先做直接绘制
- feature_missing 中同一需求出现三次以上：进入下一版范围

## 内测后的下一步输入

内测报告直接决定阶段 2 的优先级排序：3D 导入展平、充棉模拟、直接绘制工具三者谁先做，由数据说话，不预设。
